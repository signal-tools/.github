# Contributing

Thank you for helping improve Signal Tools.

Before opening a pull request:

1. read the affected repository's README and contribution guidance;
2. keep the change focused and add tests for behavioral changes;
3. run the repository's documented validation commands;
4. explain user-visible behavior and compatibility effects; and
5. include the validation you ran.

Use GitHub's private vulnerability-reporting flow in the affected repository instead of a public issue for
security concerns.
