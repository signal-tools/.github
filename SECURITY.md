# Security policy

Please report suspected vulnerabilities privately through the affected repository:

- [`signal-tools/signal`](https://github.com/signal-tools/signal/security/advisories/new)
- [`signal-tools/signal-collections`](https://github.com/signal-tools/signal-collections/security/advisories/new)

Do not open a public issue for an undisclosed vulnerability. Supported-version information and response details
are maintained in each repository's security policy.
