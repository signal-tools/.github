# Support

Before opening an issue, check the affected package README and search existing issues:

- [`signal-tools/signal`](https://github.com/signal-tools/signal/issues)
- [`signal-tools/signal-collections`](https://github.com/signal-tools/signal-collections/issues)

Include your runtime and package versions plus a minimal reproduction when reporting behavior. Security
vulnerabilities must use the private reporting path described in the [security policy](SECURITY.md).
