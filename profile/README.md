# Signal Tools

Small, standards-focused utilities for JavaScript Signals.

- [`signal-tools/signal`](https://github.com/signal-tools/signal) — a tiny implementation of the
  [TC39 Signals proposal](https://github.com/tc39/proposal-signals), packaged as `@signal-tools/signal`.
- [`signal-tools/signal-collections`](https://github.com/signal-tools/signal-collections) — signal-aware
  Array, Map, Set, and Object collections, packaged as `@signal-tools/collections`.
- [`signal-tools/signal-dom`](https://github.com/signal-tools/signal-dom) — functional, signal-aware DOM
  construction and templating utilities, packaged as `@signal-utils/dom`.

These projects are preparing their first public releases. See each repository README for its current API,
compatibility, and local development instructions.

Please report suspected vulnerabilities privately through the affected repository's security page.
